# 论文图书馆 PaperLib

本地优先的个人科研阅读工作站：上传论文 PDF → AI 翻译成排版一一对应的中文 → 双语精读批注 → 沉淀为研究总表与个人知识库。

## 快速开始

**普通使用**：双击 `启动.bat`（首次运行自动安装依赖并构建前端），浏览器会自动打开 http://127.0.0.1:8300

**开发模式**：双击 `dev.bat`（后端 8300 热重载 + 前端 5173 热更新）

要求：Python 3.10+、Node.js 18+。

## 第一次使用

1. 打开 **设置** 页，配置翻译引擎：
   - 推荐 **DeepSeek**（便宜，一篇 10 页论文约几分钱）或 **智谱 GLM**（`glm-4-flash` 免费）；
   - 不想先配 Key？先用 **Mock 测试引擎** 跑通全流程（译文是假的，仅体验界面）。
2. （可选）解析引擎换成 **MinerU 云端**：公式/表格效果最好，到 [mineru.net](https://mineru.net) 申请免费 API Token；默认内置引擎零配置、速度快，但公式无法还原成 LaTeX。
3. 去 **论文库** 拖入一篇 PDF → 自动解析+翻译 → 点「阅读」进入阅读器。
4. 阅读器里：选中文字 → 高亮/加粗/批注/记问题；段落工具条 → 重译/编辑译文/小结；顶栏切换 中文/英文/对照 与 原PDF并排。
5. 读完后到 **研究总表** 填写：研究问题 / 解决方案 / 创新点 / 我的思考 / 一句话收获，问题在那里追踪解决情况，可导出 CSV/Markdown。

## 数据在哪

全部在项目下的 `data/` 目录（SQLite + PDF + 图片）：

- 备份：设置页一键下载 zip，或直接复制整个 `data/` 目录
- 恢复：解压/覆盖 `data/` 目录后重启

## 结构

```
backend/   FastAPI 服务（解析/翻译/批注/总表 API）
frontend/  Vue3 前端（阅读器/论文库/总表/设置）
data/      用户数据（SQLite + 每篇论文的 PDF、块结构、图片）
docs/      产品文档（需求梳理）
tools/     辅助脚本（生成测试 PDF 等）
```

## 已知限制（一期）

- 内置解析引擎：复杂公式只能保留原始字符（不能还原 LaTeX）、矢量图提取不到——公式密集的论文请用 MinerU 引擎；
- 翻译引擎走 OpenAI 兼容协议，Ollama 本地模型在设置里选「Ollama」填地址即可用（需本机自行安装）；
- 阅读器批注锚定段落与锚文本：单段重译后高亮/批注不丢，整篇强制重译且文字大改时可能显示「锚点未找到」（批注内容仍在侧栏可见）。
